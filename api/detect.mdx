Find secrets in code. Returns detection details with category, confidence, and line range.

<Note>
This endpoint is served by the local [daemon](/concepts/daemon) on `127.0.0.1:19532`, which runs the aegis-core detection engine on your machine. The hosted gateway and the Cloud API do not serve it. The daemon accepts requests from the local machine without an API key.
</Note>

## POST /detect

Send code to the daemon and get back secret detection results.

<CodeGroup>
```bash curl
curl -X POST http://localhost:19532/detect \
  -H "Content-Type: application/json" \
  -d '{
    "content": "const key = \"AKIAIOSFODNN7EXAMPLE\";",
    "filename": "config.ts"
  }'
```

```typescript TypeScript
const response = await fetch("http://localhost:19532/detect", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    content: 'const key = "AKIAIOSFODNN7EXAMPLE";',
    filename: "config.ts"
  })
});
const result = await response.json();
```

```python Python
import requests

result = requests.post(
    "http://localhost:19532/detect",
    json={
        "content": 'const key = "AKIAIOSFODNN7EXAMPLE";',
        "filename": "config.ts"
    }
).json()
```
</CodeGroup>

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `content` | string | Yes | Code to scan for secrets |
| `filename` | string | No | File name (helps with detection context) |

### Response

```json
{
  "detections": [
    {
      "category": "AwsAccessKey",
      "confidence": 0.95,
      "description": "AWS Access Key ID (20 chars)",
      "start_line": 1,
      "end_line": 1
    }
  ],
  "count": 1
}
```

| Field | Type | Description |
|-------|------|-------------|
| `detections` | array | List of detected secrets |
| `count` | number | Total detections |

### Detection object

| Field | Type | Description |
|-------|------|-------------|
| `category` | string | Secret type (for example `AwsAccessKey`) |
| `confidence` | number | 0.0 to 1.0 confidence score |
| `description` | string | Human-readable description |
| `start_line` | number | Start line (1-indexed) |
| `end_line` | number | End line (1-indexed) |

## Minimal request

A shorter request, with only the required fields:

```bash
curl -X POST http://localhost:19532/detect \
  -H "Content-Type: application/json" \
  -d '{"content": "const key = \"AKIAIOSFODNN7EXAMPLE\";", "filename": "config.ts"}'
```

The daemon runs the aegis-core detection engine offline. It does not need network access to the gateway.
