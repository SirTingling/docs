Scan code for security issues using Sentinel rules. Returns detected issues with severity, location, and fix suggestions.

<Note>
This endpoint is served by the local [daemon](/concepts/daemon) on `127.0.0.1:19532`, which runs the Sentinel scan engine on your machine. The hosted gateway and the Cloud API do not serve it. The daemon accepts requests from the local machine without an API key.
</Note>

## POST /scan

Send code to the daemon and get back Sentinel scan results.

<CodeGroup>
```bash curl
curl -X POST http://localhost:19532/scan \
  -H "Content-Type: application/json" \
  -d '{
    "content": "const query = `SELECT * FROM users WHERE id = ${userInput}`;",
    "filename": "handler.ts",
    "language": "typescript"
  }'
```

```typescript TypeScript
const response = await fetch("http://localhost:19532/scan", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    content: 'const query = `SELECT * FROM users WHERE id = ${userInput}`;',
    filename: "handler.ts",
    language: "typescript"
  })
});
const result = await response.json();
```

```python Python
import requests

result = requests.post(
    "http://localhost:19532/scan",
    json={
        "content": 'const query = `SELECT * FROM users WHERE id = ${userInput}`;',
        "filename": "handler.ts",
        "language": "typescript"
    }
).json()
```
</CodeGroup>

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `content` | string | Yes | Code to scan |
| `filename` | string | No | File name (helps with language detection) |
| `language` | string | No | Language identifier |

### Response

```json
{
  "scan_id": "01m62c1eycqeaps0v2kzw7wvmx",
  "passed": false,
  "issues": [
    {
      "rule_id": "SEC-001",
      "severity": "Critical",
      "message": "SQL query built with template literal interpolation, vulnerable to injection",
      "line": 1,
      "column": null,
      "fix_suggestion": "Use parameterized queries"
    }
  ],
  "engine_duration_ms": 2
}
```

| Field | Type | Description |
|-------|------|-------------|
| `scan_id` | string | Unique scan identifier |
| `passed` | boolean | `true` if no issues found |
| `issues` | array | List of detected issues |
| `engine_duration_ms` | number | Scan engine time in milliseconds |

### Issue object

| Field | Type | Description |
|-------|------|-------------|
| `rule_id` | string | Rule that triggered (for example `SEC-001`) |
| `severity` | string | `Info`, `Low`, `Medium`, `High`, or `Critical` |
| `message` | string | Human-readable description |
| `line` | number or null | Line number (1-indexed) |
| `column` | number or null | Column number (1-indexed) |
| `fix_suggestion` | string | Suggested fix |

## Minimal request

A shorter request, with only the required fields:

```bash
curl -X POST http://localhost:19532/scan \
  -H "Content-Type: application/json" \
  -d '{"content": "eval(userInput)", "filename": "app.js"}'
```

The daemon runs the Sentinel scan engine offline. It does not need network access to the gateway.
